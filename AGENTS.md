# Agents

Astro site built from Figma on the Relume Styleguide. Procedures live in `.agents/skills/`
(Claude Code loads them through `.claude/skills/`).

- `figma-slice`: slice a Figma page into Content Components, generate tokens.css from Figma Variables.
  Read its **This project** section before any work on this site.

Dev server: `npm run dev`. Before committing: `npm run check && npm run build`.
